State dependency disclosures: D-007

States: default, checked, focus-visible, disabled
  default: Named content on the default surface. [Native text and structure.]
  checked: Selected fill and a check indicator. [Native checked state.]
  focus-visible: Dashed focus ring. [Native keyboard focus position.]
  disabled: Disabled semantic foreground, background and border at full opacity. [Native disabled state blocks activation.]

Keyboard:
  Tab / Shift+Tab: Enter the native radio group once and leave it.
  Arrow keys / Space: Use native radio selection and wrapping.

ARIA: Native fieldset, legend and radio inputs
Responsive: Wrap labels and actions without changing source order. Use logical spacing in RTL. Preserve native target sizes at both densities; only bounded data regions may scroll horizontally.
Portability: Choose one value from a short labelled set using native radios. This changes a value; use tabs for associated content panels. Native names, required checks, disabled fieldsets and form reset are preserved.
  native: Use equivalent native semantics and approved roles; record any unsupported behavior as a mapping deviation.
