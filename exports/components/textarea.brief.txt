Keyboard:
  Tab / Shift+Tab: Moves focus in and out; Tab never inserts a tab character.
  Enter: Inserts a line break; never submits.
  Ctrl+Enter / Cmd+Enter: May submit the owning form when the host binds it; announced in the help text.

ARIA: native <textarea> with <label> (https://www.w3.org/WAI/ARIA/apg/practices/forms/)
Responsive: Fills its field container with min-width 0 and width 100%; the resize handle is vertical only so the box can never widen past its container at 320px. RTL keeps the handle on the inline-end corner.
Portability: native <textarea> plus <label>; rows="3" minimum; resize vertical; the count is a live region with aria-live="polite" updated at most once per second; the dashed ring through outline, never box-shadow.
  native: GTK4 TextView inside a ScrolledWindow with a frame.
  native: Qt QPlainTextEdit stylesheet; invalid through a dynamic property selector.
  native: Terminal UI: bordered multi-line box; the count in the bottom border.

Rules: use only these values; no invented colours; radius 0; borders 1px (2px emphasis); focus is a 1px dashed ring, selection is a fill;
do not restyle unrelated elements; report deviations per agents/consume.md; record theme.lock.json at the pinned revision.
