States: default, hover, focus-visible, invalid, disabled
  default: 1px {color.border.control} on {color.surface.input}; text {color.text.default}, tabular figures [—]
  hover: background → {color.interaction.hover.bg}; border unchanged [cursor: text]
  focus-visible: border → {color.border.active}; ring 1px dashed {color.interaction.focus.ring} at −2px [the ring]
  invalid: border 2px {color.status.danger.border}; message with the ✕ glyph [border width 1 → 2px; glyph; `aria-invalid`]
  disabled: text {color.text.disabled}; border {color.border.disabled}; background {color.interaction.disabled.bg}; no hover [`disabled`; cursor: not-allowed]

Keyboard:
  Tab / Shift+Tab: Moves between hour, minute and any meridiem segment, then out of the control (host behaviour).
  Up / Down: Steps the focused segment by one, minutes by the step attribute (host behaviour).
  Space / Alt+Down: Opens the host clock where one exists; Escape closes it.
  Enter: Submits the owning form (native).

ARIA: native <input type=time> with <label> (https://www.w3.org/WAI/ARIA/apg/practices/forms/)
Responsive: Fits its content (about 8ch) and never grows to fill the container; at 320px the box, help and message stack without clipping. RTL keeps the segments in the locale order the host chooses.
Portability: native <input type=time> with step; hosts without a time type fall back to a text field with a pattern and a format hint; color-scheme dark keeps any host popup on a dark surface.
  native: GTK4 SpinButton pair for hours and minutes inside one box.
  native: Qt QTimeEdit; section navigation is native.
  native: Terminal UI: a masked line editor (HH:MM); no popup.

Rules: use only these values; no invented colours; radius 0; borders 1px (2px emphasis); focus is a 1px dashed ring, selection is a fill;
