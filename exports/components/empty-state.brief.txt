States: default
  default: glyph, heading and sentence centred; the action, when present, below them [the worded heading; the action is a real button]

Keyboard:
  Tab: Reaches the action when present; the block itself is never focusable.
  Enter / Space: Activates the action.

ARIA: native block; a heading and a paragraph inside the region the content would fill; the action is a native <button> or <a> (https://www.w3.org/WAI/ARIA/apg/practices/landmark-regions/)
Responsive: Centred at any width; the heading and sentence wrap; at 320px the padding shrinks to 16px and the action takes the full width. RTL needs no change; the glyph has no direction.
Portability: a <div> with an <h3> (or the heading level of the region) and a <p>, placed where the list, table body or pane content would be; the action is a native <button> or <a>; a live region announces the change when a filter empties the list.
  native: GTK4 StatusPage; the icon slot holds the glyph as text.
  native: Qt a QLabel stack in the empty view; QListView placeholder text is not enough because it has no action.
  native: Terminal UI: the heading and sentence centred in the pane.
