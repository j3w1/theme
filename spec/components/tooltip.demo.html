Split the focused container horizontally Mod+h
Cycle the focused container through stacked, tabbed and split layouts. Stacked shows one title bar per window and the focused window's content; tabbed puts every title in one bar; split divides the container in the direction last chosen. The layout belongs to the container, so new windows opened inside it take the same layout, and moving a window out leaves the rest in place. Layouts survive a reload of the window manager but not a restart of the session. To change only the split direction, use Split instead.
